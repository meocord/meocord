`meocord/common` exports `splitMessage`, `truncate` and `DiscordLimits` for fitting text to what Discord accepts. `splitMessage(text)` splits text into messages of at most 2000 characters, or the `max` you give it: at line ends, a longer line at its last whitespace, never through an emoji or an accented letter. It reads code as Discord does, and closes code cut across messages at the end of one and reopens it in the next, a code block with its language and inline code with its own backticks, so each message shows its part of the text as the whole text does. `truncate(text, max)` shortens text to `max` characters with an ellipsis, closing code it cuts open. `DiscordLimits` names Discord's length limits, such as `DiscordLimits.content` and `DiscordLimits.embedDescription`. See [Formatting](https://meocord.dev/docs/4.3/formatting).

The help reply, MeoCord's own and a `presenter.messageHelp` string, splits with `splitMessage`. It splits as before, with these differences: a code block or inline code cut across messages is closed and reopened rather than cut through, no cut parts an escape from the character it escapes or leaves a backtick to pair with another in its message, a line longer than a message breaks at its last whitespace rather than at its last character, dropping the whitespace there, and a CR before a line end is no longer left at the end of a message. See the [upgrade guide](https://meocord.dev/docs/4.3/migrating).
