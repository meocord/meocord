A call is themed for the server its event names when the server is given as itself, after another value, or as the new value of an update whose old value was not cached. `@On` and `@Once` handlers for `guildCreate`, `guildUpdate`, `guildDelete` and the other events given a `Guild`, events given a server or a channel after a collection (`guildMembersChunk`, `messageDeleteBulk`, …), `threadMemberUpdate`, poll votes, and updates such as `presenceUpdate` with no cached old value now get `themeFor.guild`'s theme, as do functions `bindTheme` wraps when called with them. Before, they ran with no server's theme, and a bound function kept the theme of the call that bound it. A value from a direct message names no server, whether its `guildId` or its message's `guildId` is `null` or it is a direct message's channel or poll, so a later argument does not theme the call. See [Theming](https://meocord.dev/docs/4.3/theming#collectors-and-listeners).

An update whose old value was not cached also gets its new value's user, as it does when the old value is cached: a `presenceUpdate` is themed for its user's `themeFor.user` theme. Poll votes now also get the voter's `themeFor.user` theme. `voiceStateUpdate` and `voiceChannelEffectSend` now get their user's theme, and `autoModerationActionExecution`, `presenceUpdate` and `threadMemberUpdate` get it even when discord.js has not cached that user. `entitlementCreate`, `entitlementUpdate` and `entitlementDelete` get the entitlement's user, `subscriptionCreate`, `subscriptionUpdate` and `subscriptionDelete` the subscriber's, and `guildAuditLogEntryCreate` the executor's unless the bot took the action.

A creator is a call's user only in the event that created it: `stickerCreate`, `emojiCreate`, `guildSoundboardSoundCreate`, `threadCreate` for a newly created thread, `autoModerationRuleCreate`, `guildScheduledEventCreate` and `inviteCreate` get the creator's `themeFor.user` theme. Their update and delete events, and functions `bindTheme` wraps when called with the same values, get no user's theme. Before, `stickerUpdate`, `stickerDelete`, `emojiUpdate`, `emojiDelete`, `guildSoundboardSoundUpdate` and `guildSoundboardSoundDelete` were themed for the creator, as were bound functions given a sticker, an emoji or a sound.

`clientReady` and `ready` handlers, given the client, are no longer themed for the bot as a user.
